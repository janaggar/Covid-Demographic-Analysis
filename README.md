# Covid Demographic Analysis

A data analysis training project built with **SAS**, exploring how COVID-19 affected different demographic groups. The analysis looks at trends across age groups, geographic origin, and the most/least affected countries, and considers potential contributing causes.

## Project Overview

This project applies SAS-based statistical and demographic analysis techniques to COVID-19 data in order to answer questions such as:

- Which age groups were most and least affected by COVID-19?
- How did impact vary by country/region of origin?
- Which countries experienced the highest and lowest case/impact rates?
- What potential factors or causes might explain these differences?

## Repository Contents

- **`Demographic analysis.pdf`** - Main analysis write-up/output summarizing findings.
- **`Report1.docx`** - Written report detailing the project's methodology and conclusions.
- **`Quizes/`** - Supplementary quiz materials related to the training.
- **`notes/`** - Working notes taken during the analysis/training process.

## Tools Used

- **SAS** - for data analysis and demographic breakdowns.

## Purpose

This repository was created as part of a training exercise in demographic and statistical data analysis, using COVID-19 as the subject dataset.
